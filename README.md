# Linux Homelab Infrastructure

Self-hosted Linux infrastructure project using Fedora Linux, Navidrome, and Tailscale.

## Features

- Self-hosted music streaming
- Secure remote networking
- Linux system administration
- systemd service management

## Technologies

- Fedora Linux
- Navidrome
- Tailscale
- systemd
- Linux Networking
